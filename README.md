# dairy
программа-электронный дневник для нашего Вуз-а УФ УГТУ
Функции
- Вход от лица преподователя, студента или уч. отдела
- Регистрация новых пользователей (стунтов, сотрудников университета) и их удаление
- Выставка оценок по любым дисциплинам и их удаление
- Автоматический расчёт среднего балла студента и курса
- Автоматическая пометка задолженностей и пропусков (Н, НБ, НУ и д.р.)
- Экспорт баз данных
- Генерация готового отчёта за саместр или весь год

Визуал
- Приятный простой стиль с отсылкой на Win 7
- Интуитивно понятынй и страшему, и нвоому поколению
- наличие тёмной и светлой тем

Локализация
Русский язык
